## Программы
report.sh принимает каталог и уровень ERROR или WARN, считает сообщения по модулям и сортирует по убыванию.
Параметр --top N ограничивает вывод первыми N модулями.
При неверных аргументах выводятся ошибка и справка в stderr, код возврата — 1.
hello.py читает переданный файл в двоичном режиме и выводит размер в байтах.

## Объяснение и вывод
Собственно чтением считаются вызовы read для data/01.log, включая вызов с результатом 0 — конец файла.
Открытие, проверка метаданных и закрытие файла являются отдельными операциями.
Python дополнительно запускает интерпретатор, загружает библиотеки и модули, читает свой скрипт и выделяет память. Это создаёт накладные расходы.
Часть остальных вызовов нужна для вывода результата и завершения программы.
Для небольшого файла Python обычно выполняет больше системных вызовов, чем cat. Фактические числа приведены выше.
cat выводит содержимое файла, а hello.py — размер, поэтому операции вывода различаются.
Количество системных вызовов само по себе не определяет скорость программы.
Bash автоматизирует обработку журналов, а strace показывает обращения программ к ядру Linux.
